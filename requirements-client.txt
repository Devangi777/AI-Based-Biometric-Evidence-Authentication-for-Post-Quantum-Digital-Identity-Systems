# ---------------------------------------------------------------------------
# Client-demo dependencies (client_demo/streamlit_app.py only).
#
# Runs natively on the host OS and talks to the FastAPI server over HTTP at
# API_BASE_URL (see .env.example). The camera is read in the browser and
# streamed to this process over WebRTC (streamlit-webrtc) to record the
# liveness clip; st.camera_input is the two-photo fallback.
#
# liboqs-python is OPTIONAL here. If it is importable (e.g. macOS/Linux with
# requirements.txt installed in the same venv), the client runs ML-KEM itself
# and sends evidence over the sealed ML-KEM + AES-256-GCM channel
# (/verify-sealed). Without it (typical native Windows, see docs/SETUP.md)
# the client falls back to the plaintext /verify endpoint.
#
#   python -m venv .venv
#   source .venv/bin/activate        # Windows: .venv\Scripts\activate
#   pip install -r requirements-client.txt
# ---------------------------------------------------------------------------
